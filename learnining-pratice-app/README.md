## 📘 Project Overview - Learning & Practice React App

This project is a **hands-on learning application** built using **React.js** with **Tailwind CSS** for UI styling. The main purpose of this project is to practice core React concepts, state management, form handling, local storage operations, API integration, and testing using **Jest + React Testing Library (RTL)**.

---

## 🎯 Key Features

### 🔐 User Authentication

#### ➤ User Registration

Users can register by providing the following details:

- First Name
- Last Name
- Email Address
- Age
- Gender
- Phone Number
- Password
- Confirm Password

Data is stored in **Local Storage** to simulate a simple user database.

#### ➤ User Login

Registered users can log in using their credentials:

- Email Address
- Password

Login validation is performed using data stored in Local Storage.
